Il montaggio lo fa Claude: decide i tagli, i silenzi, il dietro le quinte, i suoni e i testi, e spiega ogni scelta. Senza Claude collegato l'app non genera. Serve un accesso a Claude, in uno dei due modi del passo successivo.

Opzione A — Claude Code CLI consigliato

Usa il tuo login di Claude Code, nessuna API key da gestire.

npm install -g @anthropic-ai/claude-code

Poi autenticati una volta: apri un terminale, lancia claude ed esegui /login.

Opzione B — API key Anthropic

Imposta la variabile d'ambiente prima di aprire l'app:

export ANTHROPIC_API_KEY="sk-ant-…"

Dopo aver configurato, torna al passo 3 e premi “Testa connessione”.
